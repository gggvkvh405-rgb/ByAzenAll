# ByAzen Desktop Suite

Тёмная настольная библиотека ByAzen с каталогом из 185 приложений в 14 направлениях. Каждый инструмент оформлен под единым брендом ByAzen и имеет собственную уникальную Lucide-иконку.

## Запуск

```bash
npm install
npm run dev
```

## Что внутри

- поиск по приложениям, фильтры по категориям, сортировка и grid/list-вид;
- избранное и недавно открытые приложения сохраняются в браузере;
- рабочая область для каждой идеи с демонстрационным интерактивным макетом по направлению;
- адаптивная тёмная тема, клавиатурный поиск `Ctrl/⌘ + K` и локальное сохранение заметок/задач.

Это UI-прототип единой библиотеки, а не набор из 185 отдельных нативных бинарников. Интеграции с файлами, ОС, сетью и устройствами в демо не выполняются.

## Сборка Windows EXE

```bash
npm install
npm run desktop:win
```

Собирай на Windows. В папке `release/` появятся два варианта для 64-разрядной Windows 10 или 11:

- `ByAzen-<версия>-portable.exe` — один файл, установка не нужна. При запуске он распаковывает приложение во временную папку.
- `ByAzen-<версия>-windows-x64.zip` — если portable EXE не открывается, распакуй весь архив в отдельную папку и запусти `ByAzen.exe` из неё. Остальные файлы должны остаться рядом с EXE.

GitHub Actions проверяет запуск каждой сборки на Windows перед публикацией артефакта.

## Если Electron не открывает интерфейс

В сборке **Build offline ByAzen (no Electron)** есть два варианта, которым не нужен Electron или локальный сервер:

- `ByAzen-offline.html` — один HTML-файл со всем каталогом. Открой его в Chrome, Edge или Firefox; интернет не нужен. Его можно собрать локально командой `npm run build:offline` (результат: `release/offline/index.html`).
- `ByAzen-browser.exe` — лаунчер Windows x64 (.NET Framework 4), который сохраняет тот же HTML в `%LOCALAPPDATA%\ByAzen\Offline` и открывает его в браузере по умолчанию. Это не отдельное окно приложения.

Избранное и заметки хранятся в выбранном браузере; данные из Electron не переносятся автоматически.
